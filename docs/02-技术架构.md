## 1. 系统架构总览

### 1.1 一句话架构

**Vue3 前端 + Express 后端 + SQLite 数据库 + 模拟数据生成器 + WebSocket 实时通道**

### 1.3 关键数据流（3 个核心场景）

**【场景 A：实时数据上报与展示】**
```
模拟器 → POST /api/sensor-data → 写库 + 规则引擎 → Socket.io broadcast
       → 前端 ECharts 增量刷新（appendData，平滑不卡顿）
```

**【场景 B：温度异常告警】**
```
数据入库 → 算法检测超阈值 → 告警模块
  ├─ ① 写告警记录
  ├─ ② WebSocket 推站内信（前端弹窗）
  ├─ ③ 邮件队列发邮件
  ├─ ④ 自动联动设备（开通风扇）
  └─ ⑤ 告警记录可查、可处理
```

**【场景 C：用户远程控制设备】**
```
前端点击开关 → POST /api/devices/:id/control
  → 写 control_logs → 通知模拟器响应
  → WebSocket 回执状态变化 → 前端 UI 反馈
```

## 2. 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | **Vue 3 + Vite** | 已有 content-sharing-platform 基础 |
| UI 库 | **Element Plus** | 组件齐全，中后台成熟 |
| 状态管理 | **Pinia** | 轻量、Vue 3 官方推荐 |
| 路由 | **Vue Router 4** | 多页面跳转 |
| 图表 | **ECharts 5** | 实时折线图、大屏图谱标配 |
| HTTP | **Axios** | 拦截器统一处理 token |
| 实时 | **Socket.io-client** | 自动重连、事件封装 |
| 后端 | **Node.js + Express** | 已跑通真注册真登录 |
| 数据库 | **SQLite（better-sqlite3）** | 零配置、文件型、够用 |
| 鉴权 | **JWT + bcrypt** | 标准化 |
| 实时推送 | **Socket.io** | 服务端 + 客户端配对 |
| 邮件 | **Nodemailer** | SMTP / QQ 邮箱 / 163 邮箱 |
| 算法 | **JS 实现（Z-Score 30 行即可）** 或 Python 独立服务 | 轻量优先 |
| 部署 | **单机本地，pm2 / node 直接跑** | 比赛演示方便 |

## 6. 关键实现要点

### 6.1 实时数据推送（核心亮点）

- 模拟器每 2s 调 `POST /api/sensor-data` 写库
- 后端写库后 → Socket.io broadcast → 所有订阅的前端 ECharts 增量更新
- 用 ECharts 的 `appendData` API，**平滑不卡顿**

### 6.2 告警链路（评委重点看）

- 规则引擎（内存 Map）匹配 sensor_id + 指标 → 超阈值写告警
- 同时：① 邮件异步队列（避免阻塞）② Socket.io 推前端弹窗
- 告警可触发自动控制（联动规则）→ 写 `control_logs`

### 6.3 算法集成（加分重点）

**推荐 Z-Score 滑动窗口异常检测**——最简单评委也认：

```javascript
// 伪代码：30 行内搞定
class ZScoreDetector {
  constructor(windowSize = 100, threshold = 3) {
    this.window = []
    this.windowSize = windowSize
    this.threshold = threshold
  }
  push(value) {
    this.window.push(value)
    if (this.window.length > this.windowSize) this.window.shift()
    if (this.window.length < 10) return { value, isAnomaly: false }
    const mean = this.window.reduce((a, b) => a + b, 0) / this.window.length
    const std = Math.sqrt(
      this.window.reduce((a, b) => a + (b - mean) ** 2, 0) / this.window.length
    )
    const z = Math.abs((value - mean) / (std || 1))
    return { value, isAnomaly: z > this.threshold, zScore: z }
  }
}
```

- **可视化对比**：异常点红色高亮，叠加"规则阈值线"和"算法检测区间"，**对比一目了然**
- 高级玩法：温度预测（LSTM/Prophet），预测未来 1h 趋势

### 6.4 模拟数据生成器

- Node 脚本 `simulator.js`，按昼夜正弦曲线 + 随机扰动生成
- 可选：**主动插入异常点 + 设备偶发掉线**，方便演示告警
- 推荐：公开数据集导入历史 + 实时叠加模拟（既真实又可控）

### 6.5 安全与可靠性

- bcrypt 哈希密码（cost=10）
- JWT 7 天过期，敏感操作短期 token
- Socket.io 鉴权：连接时校验 JWT
- SQL 全参数化（防注入）
- 邮件队列失败重试 3 次（保证告警不漏）

## 9. 关键技术风险与对策

| 风险 | 对策 |
|---|---|
| SQLite 写入并发瓶颈 | 写频 ≤ 10Hz/传感器，单机足够；后续可换 PostgreSQL |
| 模拟器掉线告警太频繁 | 加节流：同设备 5 分钟内同类告警去重 |
| 算法假阳性多 | 窗口大小 + 阈值可调，UI 提供开关对比 |
| ECharts 长时间运行内存涨 | 固定窗口（如只保留最近 500 点显示） |
| 邮件发送被拦截 | 用 QQ 邮箱授权码 + 白名单收件人 |
