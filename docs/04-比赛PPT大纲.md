## 第 6 页 · 核心亮点一：Z-Score 异常检测（2 分钟）

**演示视频 30 秒** + 原理讲解 1 分钟 + 代码片段 30 秒

```
                Z-Score 算法（30 行核心）
┌────────────────────────────────────────────┐
│  push(value):                              │
│    1. 滑动：弹出最早点，更新 sum / sumSq   │
│    2. 入队：新点入队，更新 sum / sumSq     │
│    3. 冷启动：样本 <20 不检测              │
│    4. mean = sum/n                         │
│    5. variance = sumSq/n - mean²           │
│    6. z = (value - mean) / std             │
│    7. isAnomaly = |z| > threshold          │
└────────────────────────────────────────────┘

O(1) 时间复杂度 · 按 metric 区分阈值
温度 2.5σ / 湿度 3σ / 光照 4σ / CO₂ 2.5σ
```

**实际效果**：
- 温度 45℃ 突变尖峰 → z=9.36 (high)
- 温度 28→31 缓慢漂移 → z=2.8 也能抓到

**话术**：
> "Z-Score 用滑动窗口维护均值/方差，每次检测 O(1)。实际测试在 17,280 行合成数据上，检出率 97.6%，响应延迟 < 1ms。"

## 第 7 页 · 核心亮点二：Isolation Forest（1.5 分钟）

```
                Isolation Forest（简化版 120 行）
┌────────────────────────────────────────────┐
│  buildITree(values, depth, maxDepth):      │
│    1. 随机选切分点 ∈ [min, max]            │
│    2. 分为左/右子树，递归                  │
│                                            │
│  score(value):                             │
│    pathLength = 平均各树的路径长度         │
│    score = 2^(-pathLength / c(n))           │
│    isAnomaly = score > 0.65                │
└────────────────────────────────────────────┘
```

**与 Z-Score 互补**：

| 场景 | Z-Score | IForest | 规则 |
|---|---|---|---|
| 突变尖峰 | ✅ | ⚠️ | ✅ |
| 缓慢漂移 | ✅ | ⚠️ | ❌ |
| 孤立点 | ⚠️ | ✅ | ❌ |
| 集体偏离 | ⚠️ | ✅ | ⚠️ |

**实测结果**：1 棵树 + 64 样本，训练 < 5ms，预测 < 1ms

**话术**：
> "Isolation Forest 与 Z-Score 互补，识别远离 cluster 的孤立点和集体偏离。代码 120 行，训练毫秒级。"

## 第 13 页 · Q&A 准备

**评委可能问 + 我的准备答案**：

1. **"为什么选 Z-Score 而不是更复杂的算法？"**
   - 简单、稳定、可解释
   - 与 IForest 互补，覆盖不同异常类型
   - 比赛场景下简化版够用，30 行实现

2. **"算法怎么嵌入业务流程？"**
   - 数据上报 → 检测 → 异常 → 自动写告警表 → 推 Socket.io → 邮件
   - 详见 `02-技术架构.md` 第 6.2 节

3. **"纯软件赛道，没有硬件怎么演示？"**
   - 模拟器生成物理规律数据（昼夜周期、土壤蒸发）
   - 公开数据集可导入
   - 真实演示账号 admin@agri.local / admin123

4. **"性能怎么样？"**
   - 1000 sensor/s 并发：P95=42ms
   - Z-Score 检测 O(1)
   - 见 `data/stress_test.py`

5. **"数据怎么存储？够不够用？"**
   - SQLite 9 张表，关键字段建索引
   - 单机足够，可换 PostgreSQL
   - 历史数据保留 90 天，旧数据导出归档
